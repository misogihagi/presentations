# いつも私がやっているスライドの作り方

---

私はスライドを作る時、発表する時はSlidevを使っています。

---

## なぜか？

---

### 1. Markdownによる圧倒的な効率化と簡潔さ

| メリット | 説明 |
| :--- | :--- |
| **テキスト中心の作成** | 複雑なGUI操作（マウスでのドラッグ＆ドロップ、メニュー操作）を必要とせず、**プレーンテキスト（Markdown）**でスライド内容を作成できます。これにより、コンテンツ作成に集中でき、デザイン調整の手間が減ります。 |
| **コピー＆ペーストの容易さ** | 技術文書やコード、AIが生成したテキストなど、他のソースからの情報を**整形の手間なく**簡単に取り込めます。 |
| **バージョン管理の容易さ** | Markdownファイルはテキストデータであるため、Gitなどの**バージョン管理システム**で変更履歴を追跡・管理するのが非常に容易です。（開発者や技術系プレゼンターにとって特に重要） |

---

### 2. AIとSlidevを組み合わせると強い

| メリット | 説明 |
| :--- | :--- |
| **効率的なコンテンツ生成** | AI（例：ChatGPT、Claudeなど）にプレゼンのテーマや構成を指示することで、**骨子**や**原稿**、**具体的な箇条書きの内容**などを瞬時に生成させることができます。これにより、ゼロからの資料作成時間を大幅に短縮できます。 |
| **Slidevへの即時適用** | Slidevは**Markdown**をベースとしているため、AIが生成したテキストをそのまま、またはわずかな編集でSlidevのスライドファイル（`slides.md`など）に**コピー＆ペースト**できます。 |
| **技術的な簡便さ** | 複雑なデザインソフトやPowerPointの操作を必要とせず、テキストベースでコンテンツを管理できるため、**内容の修正・更新**が容易です。 |
| **統一されたスタイル** | Slidevの**テーマ**を適用することで、AIが生成したテキストの内容に関わらず、プレゼン資料全体に統一感のあるデザインを簡単に適用できます。 |

---

### 3. プレゼンが楽

| メリット | 説明 |
| :--- | :--- |
| **GitHub Pagesに置ける** | 作成した資料はWebブラウザ上で動作します。環境に依存せず、どこでも同じように表示され、共有もリンク一つで簡単に行えます。資料の共有漏れなんて起こしません。 |
| **ライブコーディングのサポート** | コードブロックにアニメーションや編集機能を加えやすく、**技術的なデモ**や**コードの解説**を行う際に非常に強力です。 |
| **発表者モード** | 発表者専用のビューがあり、次のスライドのプレビューやタイマー、メモ（ノート）を確認しながらプレゼンを進めることができます。 |

## SlidevのMarkdownで実現する具体的な手順

この手順では、AIにプレゼン資料の構成と内容を生成させ、それをSlidevに落とし込む方法を示します。

### ステップ 1: AIによるコンテンツ生成

AIに以下の様なプロンプトを与え、Markdown形式の出力を求めます。

> **プロンプト例:**
> 「『未来の働き方』というテーマでプレゼンテーションの構成案と各スライドの具体的な内容をMarkdown形式で作成してください。各スライドは`---`で区切り、見出しには`#`または`##`、箇条書きには`*`を使用してください。」

### ステップ 2: Slidevファイル (`slides.md`) の作成・編集

AIが生成したMarkdownを、Slidevのメインファイルに貼り付け、必要に応じてSlidev独自の機能を追加します。

#### 1\. 基本設定スライドの追加

プレゼンのタイトル、発表者、日付などの情報を定義します。

```markdown
---
# theme: default
# title: 未来の働き方
# subtitle: AIと自動化がもたらす変革
# presenter: [あなたの名前]
# date: 2025/11/17
# class: 'text-center'
# layout: cover
---

# 🚀 未来の働き方
## AIと自動化がもたらす変革



---
```

#### 2\. AIが生成したコンテンツの貼り付け

AIが生成したMarkdownを、各スライドの区切り（`---`）を維持しつつ貼り付けます。

```markdown
---
# layout: default
---

## 💡 変革の背景
### なぜ今、働き方が変わるのか？

* **技術の進化:** AI、ロボティクス、IoTの急速な発展
* **グローバル化:** 場所に囚われない働き方の普及
* **価値観の多様化:** ワークライフバランスの重視、キャリアの自律性

---

## 🤖 AIによる仕事の変化
### 「代替」ではなく「協働」へ

* **自動化されるタスク:** 定型業務、データ入力、単純な分析
* **人間が注力すべき領域:**
    * **創造性:** 新しいアイデアや戦略の立案
    * **共感性:** 顧客やチームメンバーとの深いコミュニケーション
    * **複雑な意思決定:** データだけでは判断できない問題解決

---
```

#### 3\. Slidev独自の機能の追加（任意）

コンテンツに動きやデザイン性を加えます。

  * **アニメーション（`v-click`）の追加:** 箇条書きを順番に表示させることができます。

<!-- end list -->

```markdown
---
# layout: default
---

## 🚀 次世代のスキルセット

* **デジタルリテラシー:** <span v-click>AIツールを使いこなす能力</span>
* **システム思考:** <span v-click>全体像を理解し、複雑な関係性を把握する力</span>
* **レジリエンス:** <span v-click>変化に適応し、失敗から学ぶ力</span>

---
```

  * **カスタムレイアウトの利用:** スライドに画像とテキストを並べるなど、特殊なレイアウトを適用します（テーマに依存）。

<!-- end list -->

```markdown
---
# layout: two-cols-left
---

# まとめと展望

::left::
## 結論

* 未来の働き方は**柔軟性**と**人間性**が鍵
* AIは**パートナー**として活用すべき

::right::
## 展望



---
```

この方法により、**AIのスピードとコンテンツ力**と、**Slidevのシンプルで美しいプレゼン機能**を最大限に引き出すことができます。
